ChefSmart — A Two-Sided Marketplace from Zero

Problem: as co-founder of ChefSmart, a marketplace connecting consumers with independent chefs in Dublin, the job was to take the idea from a blank page to a fully specified, implementation-ready technical plan.

Approach: I wrote the full product requirements document, then designed the architecture. It's a Turborepo monorepo with a Next.js 14 web app and an Expo React Native mobile app, plus a Hono backend. Supabase is the database, Stripe Connect Express handles two-sided payments, Trigger.dev runs background jobs and Upstash Redis caches, all deployed on Render. Designed a 14-table Drizzle ORM schema with row-level security policies enforcing data access at the database layer, and wrote the complete API contract before implementation began.

Outcome: shows range beyond data science: full-stack product and system architecture, taken from a business idea to an implementation-ready plan.
